# Simple-CPUSim
a lil simple simulation show how a CPU work, but in a way like interpreter was.

This project is open-source and also it's a place so you can play with it or make your own opcode as well if you interested it. This project is my custom ASM (Assembly) and also this project is more of a CPU-style interpreter than a hardware-accurate simulator.
And the opcode is simple so you can code yourself something you like in the text file (.txt) or even upgrade it if it isn't quite right, i also appreciate if you want to upgrade it a bit tho.

I loved to explore somethings that make us today, so this project may have a bit headache (i also), but it was fun when you actually done one things like coding in ASM.

Instruction format:<br>
opcode r0 r1 r2
<br>or<br>
opcode operand0 operand1 operand2
